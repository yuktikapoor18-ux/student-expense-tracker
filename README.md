# 💰 Student Expense Tracker

A beginner-friendly web application that helps students track and manage their daily expenses.

## 🚀 Live Demo

https://yuktikapoor18-ux.github.io/student-expense-tracker/

## ✨ Features

- Add daily expenses
- Categorize expenses
- Select expense dates
- View total amount spent
- View total number of expenses
- Search expenses
- Filter expenses by category
- Sort expenses by date or amount
- Edit existing expenses
- Delete individual expenses
- Clear all expenses
- Export expenses as CSV
- Data is saved using browser Local Storage
- Responsive and clean user interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage
- Git & GitHub
- GitHub Pages
